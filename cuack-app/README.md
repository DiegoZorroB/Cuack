# PROYECTO PAGINA WEB CUACK:
CUACK= Community Updates, Arcade & Content Kit
En español significa: Kit de Contenido, Arcade y Actualizaciones de la comunidad.





## Pasos para ejecutar el proyecto en visual code

# 1: Clonar el repositorio
Abrir la paleta de comandos en Visual Code oprimiendo Ctrl + Shift + P
Escribir Git: Clone en la barra que aparece y seleccionar esa opción presionando Enter.
Pegar la URL y elegir la carpeta en donde se almacenará el proyecto
URL: https://github.com/DiegoZorroB/Cuack.git

# 2: Instalar dependencias
En visual code, abrir la terminar oprimiendo Ctrl + ñ
Acceder a la carpeta llamada cuack-app mediante cd (nombre carpeta) hasta llegar a la anteriormente mencionada (cuack-app)
Pegar los siguientes comandos para instalar las respectivas dependencias de node, bootstrap, React Router:
npm install
npm install react-router-dom
npm install bootstrap

# 3: Inicializar el servidor
En la terminal, el la carpeta cuack-app, ejecutar el siguiente comando:
npm run dev

# 3: Abrir la pagina web
Despues de haber inicializado el servidor con el comando npm run dev en la terminal, escribir ahí mismo la letra o y oprimir la tecla ENTER, de esta forma se abrirá la página web en
el navegador predeterminado
